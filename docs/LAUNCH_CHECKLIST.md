# قائمة التحقق للإطلاق التجاري (Launch Checklist) — REEVITA Backend

تتبع الحالة الحقيقية لكل عنصر من عناصر النظام قبل فتح المتجر للجمهور.

تم تطبيق مخطط قاعدة البيانات والبيانات الأولية على مشروع Supabase `reevita-store` يوم 28 أكتوبر 2026. يحتوي المشروع حالياً على 22 ملف ترحيل مطبقاً و19 جدولاً عاماً محمياً بـ RLS، مع عدم وجود طلبات عملاء وقت المراجعة.

---

## 1. قاعدة البيانات والـ Schema والأمان
- [x] **تطبيق Migrations من الصفر:** الاختبارات المحلية تطبق ملفات الترحيل الـ22 من البداية، كما طُبقت على مشروع Supabase.
- [x] **بيانات أولية مكتملة (Seed):** 27 محافظة مصرية، أسعار شحن، 14 منتجاً حقيقياً لـ REEVITA، و14 صورة WebP موجودة.
- [x] **تفعيل RLS بنسبة 100%:** مفعّل على الجداول العامة الـ19، مع صلاحيات صفوف محددة حسب الاستخدام.
- [x] **حماية التزامن ومنع الـ Overselling:** مُختبر بطلبين متزامنين على آخر قطعة مع قفل الصفوف `FOR UPDATE`.
- [x] **حساب الأسعار والشحن سيرفر-سايد:** لا يمكن التلاعب بالسعر أو الإجمالي من طرف العميل.
- [x] **التحقق من الهاتف وتطبيعه:** يدعم شبكات المحمول المصرية الأربعة (010, 011, 012, 015).
- [x] **آلة حالات الطلب:** انتقالات الحالات الصارمة وإعادة المخزون التلقائي عند الرفض والإلغاء.
- [x] **حماية الخصوصية في التتبع (Anti-IDOR):** التتبع يشترط رقم الطلب ورقم الهاتف ولا يسرب العناوين أو الإيميل.

---

## 2. التكاملات والخدمات الخارجية

| الخدمة / الميزة | الحالة الحقيقية | الإجراء المطلوب قبل الإطلاق |
|---|---|---|
| **الدفع عند الاستلام (COD)** | ✅ جاهز ومُختبَر | لا شيء، جاهز للاستخدام الفوري. |
| **الشحن اليدوي (مصر)** | ✅ جاهز ومُختبَر | إدخال اسم شركة الشحن ورقم التتبع في لوحة الأدمن. |
| **الدفع الإلكتروني (Paymob/Fawry)** | ❌ معطل مقصوداً | واجهة `PaymentProvider` جاهزة للتفعيل عند رغبة المالك. |
| **ربط API شركات الشحن (Bosta/J&T)** | ⚠️ واجهة فقط | واجهة `ShippingProvider` جاهزة للتفعيل عند توفير الـ API Keys. |
| **إشعارات البريد الإلكتروني (Resend)** | ⚠️ يحتاج Credentials | غير مفعل حالياً حتى توفير الـ API Key. |
| **حماية الكابتشا (Turnstile)** | ⚠️ يحتاج Credentials | غير مفعل حالياً حتى توفير Site Key و Secret Key. |

---

## 3. جهوزية واجهة المتجر (Next.js 16 Storefront)
- [x] **بناء واجهة المتجر بالكامل:** واجهة فاخرة بالعربية (RTL) مبنية بـ Next.js 16 (App Router) و Tailwind CSS 4 و Lucide Icons.
- [x] **الكتالوج الحقيقي (14 منتج):** 14 منتجاً حقيقياً لـ REEVITA مع صور WebP عالية الجودة محسوبة بـ Blur placeholders.
- [x] **سلة المشتريات:** سلة منبثقة (Drawer) وصفحة سلة كاملة مع شريط تقدم الشحن المجاني التفاعلي.
- [x] **إتمام الطلب (Checkout COD):** مخصص للسوق المصري (27 محافظة، حساب شحن حي، تحقق من الهاتف، ومنع التلاعب بالأسعار).
- [x] **تتبع الطلبات (Anti-IDOR):** شاشة تتبع آمنة برقم الطلب ورقم الهاتف مع الخط الزمني للحالات الخمس.
- [x] **حسابات العملاء:** تسجيل ودخول وتصفح الطلبات السابقة عبر Supabase Auth.
- [x] **لوحة تحكم الإدارة (Admin Dashboard):** إدارة الطلبات وتغيير الحالات، إدخال بوالص الشحن، تعديل المخزون، وتعديل تسعير الشحن للمحافظات.
- [x] **النمط المزدوج (Dual Mode):** يعمل فورياً في وضع العرض التجريبي (Demo Mode) بدون مفاتيح، وينتقل تلقائياً للربط السحابي بـ Supabase عند ملء المتغيرات.
- [x] **الفحوصات الشاملة:** Typecheck سليم، ESLint نظيف، 10/10 اختبارات باك إند ناجحة، وبناء Next.js ناجح.
